# 《奶娃》跑酷 × 2048 合成 · 网页版 Demo

**在线游玩：https://hcjun11.github.io/naiwa-game/**

根据《奶娃游戏商业计划书路演 PPT》开发的可玩网页 Demo（v0.9.4）：地铁跑酷式操作——左右滑动换道、上滑跳跃、下滑滑铲；边躲障碍边收集数字方块，2 合 4、4 合 8……合成升级、三选一强化并挑战实时排行榜。

- 玩法：3 条跑道自动前进并随时间加速；低栏要跳、横杆要滑、木箱岩石需换道；底部 5 格合成槽同数自动合成；3 颗心、4 种道具；冲刺模式 60 秒限时；金币解锁 5 套奶娃外观与 4 套赛道主题。
- 动作手感（v0.9.4）：滑铲中按跳跃立即取消滑铲并起跳；空中下落按跳跃会缓冲到落地瞬间自动连跳；空中按滑铲加速下坠、落地立即接滑铲——滑铲↔跳跃无缝衔接。
- 跳过数字（v0.9.4）：跳起来会跳过脚下的数字方块（不拾取），让合成槽更可控、合成路线更多选择。
- Roguelike 强化（v0.9.4）：每次首次合成出新的数字（8/16/32…）会暂停并三选一强化，共 14 种强化（普通/稀有/史诗三档），仅本局生效——分数倍率、合成大师、连击延长、磁力吸附、弹跳、滑铲精通、护心、护盾、无敌、道具延时、幸运方块、二次机会、净化冲刺等。
- 角色：奶娃为 3D 体积光渲染质感（主光/环境光/轮廓光 + AO + 三层接触阴影），换道时 3D 转向；滑铲↔跳跃姿态融合、空中下坠有专属姿态。
- 在线排行榜：最近 12 小时真实玩家成绩实时汇总（打开排行榜自动刷新，断网回退本地榜）；昵称与分数公开，不含账号信息。
- 操作：手机左右滑动换道、上滑跳跃、下滑滑铲（也可点击左右半区换道）；桌面 ←→ / A D 换道，↑ / W / 空格跳跃，↓ / S 滑铲，Esc/P 暂停；强化三选一用 1/2/3 或 ←→ + Enter，也可直接点击卡片。
- 技术：原生 Canvas 2D + 伪 3D 投影、WebAudio 合成音效、零依赖零构建。

> 本仓库为演示版本，激励广告为模拟流程；排行榜为轻量公共消息服务实现，长期运营建议替换为正式后端。素材参考图由项目发起人提供，仅用于本项目演示。
