# 《奶娃》跑酷 × 2048 合成 · 网页版 Demo

在线游玩：https://hcjun11.github.io/naiwa-game/

根据《奶娃游戏商业计划书路演 PPT》开发的可玩网页 Demo：单指左右滑动换道，边躲障碍边收集数字方块，2 合 4、4 合 8……合成升级并挑战高分。

- 玩法：3 条跑道自动前进，收集数字方块进入底部 5 格合成槽，同数自动合成；3 颗心，撞障碍扣心；冲刺模式 60 秒限时；护盾/减速/磁铁/双倍 4 种道具；金币解锁 5 套奶娃外观与 4 套赛道主题；本地排行榜与存档。
- 操作：手机左右滑动 / 点击屏幕左右半区；桌面 ←→ 或 A D，Esc/P 暂停。
- 技术：原生 Canvas 2D + 伪 3D 投影、WebAudio 合成音效、零依赖零构建，直接打开 index.html 即可运行。

> 本仓库为演示版本，激励广告为模拟流程，排行榜与存档保存在浏览器本地。
