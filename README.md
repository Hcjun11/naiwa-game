# 《奶娃》跑酷 × 2048 合成 · 网页版 Demo

**在线游玩：https://hcjun11.github.io/naiwa-game/**

根据《奶娃游戏商业计划书路演 PPT》开发的可玩网页 Demo：单指左右滑动换道，边躲障碍边收集数字方块，2 合 4、4 合 8……合成升级并挑战高分。

- 玩法：3 条跑道自动前进并随时间加速；底部 5 格合成槽同数自动合成；3 颗心、4 种道具；冲刺模式 60 秒限时；金币解锁 5 套奶娃外观与 4 套赛道主题。
- 在线排行榜：最近 12 小时真实玩家成绩实时汇总（打开排行榜自动刷新，断网回退本地榜）；昵称与分数公开，不含账号信息。
- 操作：手机左右滑动 / 点击屏幕左右半区；桌面 ←→ 或 A D，Esc/P 暂停。
- 技术：原生 Canvas 2D + 伪 3D 投影、WebAudio 合成音效、零依赖零构建。

> 本仓库为演示版本，激励广告为模拟流程；排行榜为轻量公共消息服务实现，长期运营建议替换为正式后端。素材参考图由项目发起人提供，仅用于本项目演示。
